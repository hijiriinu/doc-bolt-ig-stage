# ドク・ボルト解説サイト

PT・OT学生や若手向けに、1テーマを約5000字・会話形式・触れる仕掛けつきで解説し、Instagramから配るための手順。完成例は `kokushi/index.html`（国試の勉強法）。

## 守ること

- **根拠**：数値は原著（PubMed等）で確認できたものだけ。各主張に「確立／有力／推測」のチップと出典（PMIDかDOI）を付ける。確認できなかったPMIDは載せずDOIか雑誌情報にする。図から読んだ値は「およその値」と書く。
- **キャラ**：ドク・ボルト（白髪の博士、語尾「デス」、驚くと「なんてこった！」）と学生。学生に名前は付けない。既存の映画を連想させる固有名詞・小道具（タイムマシン、特定の台詞）は使わない。
- **トーン**：結論→研究→ドクのひと言。前置きなし。
- **個人情報**：院内データ・患者情報は載せない。

## 手順

1. **骨子を先に出す**：目的、対象、章立て（各章のテーマ・根拠・字数）、仕掛け案を表で返し、方向が合ってから作る。
2. **根拠を確認**：WebSearchで `pubmed.ncbi.nlm.nih.gov` に絞って書誌とPMIDを確認する（この環境ではPubMed APIに直接つながらないことがある）。公式統計は一次ソース（厚労省など）。
3. **ページを書く**：`assets/site-template.html` を土台にする。構成と仕掛けの型はそのまま流用し、本文と LAB の中身を差し替える。
   - 入口：走るローディング（約2.6秒、タップでスキップ、1訪問1回、動きを減らす設定では出さない）
   - 冒頭：○×クイズ → 正答数でタイプ診断 → 共有ボタン
   - 各章：会話の吹き出し＋LAB（数値が逆転するグラフ、ジェネレーター、シャッフル、スライダーなど、その章の研究を体験できるもの）
   - 終盤：チェックリスト（localStorage、全部で紙吹雪）、スクショ用まとめカード、もう一度クイズ（想起練習）、Instagramフォロー、参考文献
4. **キャラ画像**：既存投稿から切り抜くときは `python3 scripts/cut_character.py 元画像.jpg x1,y1,x2,y2 out.png`（背景を透過）。吹き出しのしっぽが残ったら消す。標準の2枚は `assets/` にある。
5. **プレビュー**：Artifactとして公開し（画像は `files` で同梱）、ユーザーに確認してもらう。
6. **告知カルーセル**：`assets/carousel-template.html` を書き換え、`node scripts/render.js carousel.html .s slide_ 1080 1350` で1080×1350を書き出す（既存投稿と同じ赤ライン・オフホワイト・`n / 6`）。キャプションも添える。`images/` には置かない（自動投稿パイプラインが使うフォルダ）。
7. **OGP画像**：`assets/og-template.html` を書き換え、`node scripts/render.js og.html .og og_ 1200 630` → `og.png`。
8. **公開**：`python3 scripts/build_pages.py ページ.html <slug> https://hijiriinu.github.io/doc-bolt-ig-stage/<slug>/ "説明文"` でリポジトリ直下 `<slug>/` に書き出し、ブランチ→ドラフトPR。mainにマージされるとGitHub Pagesで公開される。サイト内の `SITE_URL` も同じURLにする。

## 仕上げチェック

- スマホ幅（390px）で横スクロールなし、JSエラーなし（`render.js` と同じ要領でPlaywrightで確認）
- ライト／ダーク両方で読める
- 出典チップと参考文献の抜けがない
- フォロー導線のURLが `https://www.instagram.com/doc_bolt_pt/`
